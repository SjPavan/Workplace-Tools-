# Initial Setup Guide

After completing the onboarding wizard, follow this guide to complete your setup.

### Preferences
- [ ] Theme selected

### Notifications
- [ ] Notification preferences set

## Step-by-Step Setup

### 1. Verify Your Profile (2 minutes)

Navigate to **Settings** → **Profile**:

**What to Check:**
- Display name is correct
- Email is correct
- Timezone matches your location
- Language is preferred language

**Edit if Needed:**
1. Click "Edit Profile"
2. Make changes
3. Click "Save Changes"
4. Confirm success

### 2. Configure Security (3 minutes)

Go to **Settings** → **Security**:

**Email Verification:**
- Check status: ✓ Verified or ⏳ Pending
- If pending: Look for email, click link
- Resend email if needed

**Password Settings:**
- Current password strength shown
- Recommendation if weak
- Option to change password

**Change Password if Needed:**
1. Click "Change Password"
2. Enter current password
3. Enter new password (twice)
4. Click "Update"
5. Confirm on new login

**Security Recommendations:**
- ✓ Use password manager
- ✓ Use unique password
- ✓ Enable 2FA when available
- ✓ Review active sessions

### 3. Customize Preferences (3 minutes)

Visit **Settings** → **Preferences**:

**Theme Selection:**
- Choose Light, Dark, or Auto
- Changes apply immediately
- Preference saves automatically

**Accessibility:**
- Enable features you need:
  - High contrast
  - Larger font
  - Keyboard help
  - Screen reader info

**Language & Localization:**
- Select preferred language
- Date/time format preferences
- Changes apply to interface

**Advanced Options:**
- Browser cache settings
- Performance preferences
- Developer options (if applicable)

### 4. Set Notification Preferences (2 minutes)

Go to **Settings** → **Notifications**:

**Email Notifications:**
- [ ] Activity digest (weekly)
- [ ] Important alerts
- [ ] Security notifications
- [ ] Feature announcements

**Browser Notifications (if enabled):**
- [ ] Permission granted
- [ ] Alert types configured
- [ ] Quiet hours set (optional)

**Data & Analytics:**
- [ ] Anonymous analytics (for improvement)
- [ ] Crash reports
- [ ] Marketing emails

### 5. Review Active Sessions (2 minutes)

Navigate to **Settings** → **Sessions**:

**View Sessions:**
- Current session (this device)
- Other active sessions
- Last activity time
- Device information

**Security Check:**
- Recognize all devices?
- Unexpected sessions? Sign out
- Revoke old sessions from unused devices

**Sign Out Unused Devices:**
1. Find device in list
2. Click "Sign Out"
3. Confirm action
4. Device logged out immediately

## Feature Configuration

### Enable PWA (Optional but Recommended)

Progressive Web App allows offline use and app installation:

**Desktop Installation:**
1. Look for install icon (top-right)
2. Click "Install app"
3. Choose installation location
4. App launches in standalone window

**Mobile Installation (iOS):**
1. Open app in Safari
2. Tap Share button
3. Tap "Add to Home Screen"
4. Choose name
5. Tap "Add"
6. Tap home screen to launch

**Mobile Installation (Android):**
1. Open app in Chrome
2. Tap menu (three dots)
3. Tap "Install app"
4. Confirm
5. App added to home screen

### Enable Browser Notifications (Optional)

1. Go to **Settings** → **Notifications**
2. Click "Enable Browser Notifications"
3. Browser prompts for permission
4. Click "Allow"
5. Notifications configured

### Connect External Services (If Available)

If your organization uses integrations:
1. Go to **Settings** → **Integrations**
2. Find service to connect
3. Click "Connect"
4. Authorize application
5. Service now integrated

## Backup & Recovery

### Create Backups

1. Go to **Settings** → **Data**
2. Click "Export Data"
3. Choose format (JSON recommended)
4. Download file
5. Store safely

**Backup Schedule:**
- Initial backup after setup
- Regular backups (monthly)
- Before major changes
- Before vacations

### Recovery Process

If needed to restore:
1. Export current data first
2. Document current state
3. Contact support if needed
4. Follow recovery instructions
