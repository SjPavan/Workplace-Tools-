# Onboarding Wizard Guide

The Onboarding Wizard guides new users through setting up Workplace Tools efficiently.

## Wizard Overview

The wizard appears after first login and takes approximately **5-10 minutes** to complete. You can restart it anytime from Settings.

```
┌─────────────────────────────────────────┐
│        Welcome to Workplace Tools       │
├─────────────────────────────────────────┤
│  Step 1 of 5 [████░░░░░░]               │
│                                         │
│  Welcome!                               │
│  Let's set up your account.             │
│                                         │
│  [← Back]  [Skip]  [Next →]             │
└─────────────────────────────────────────┘
```

## Wizard Steps

### Step 1: Welcome & Introduction

**Duration:** 1-2 minutes

**What You'll Learn:**
- Overview of Workplace Tools
- Key features introduction
- What to expect from the wizard

**Actions:**
- Read welcome message
- Review key points
- Click "Next" to continue

**Skip Option:** You can skip to dashboard at any point

---

### Step 2: Profile Setup

**Duration:** 2-3 minutes

**What You'll Set Up:**
- Display name
- Profile avatar (optional)
- Timezone
- Preferred language/locale

**Form Fields:**
```
Display Name: [Your Name        ]
Email:        [your@email.com   ] (read-only)
Timezone:     [UTC v]
Language:     [English v]
Avatar:       [Upload or Skip]
```

**Why This Matters:**
- Display name shown to other users
- Timezone ensures correct timestamps
- Language determines UI language
- Avatar personalizes your account

**Next Steps:** Click "Next" when complete

---

### Step 3: Privacy & Preferences

**Duration:** 2-3 minutes

**What You'll Choose:**
- Theme preference (light/dark)
- Accessibility settings
- Notification preferences
- Data sharing options

**Options:**

**Theme Selection:**
- Light (default)
- Dark
- Auto (follows system)

**Accessibility:**
- High contrast mode
- Font size preference
- Keyboard navigation help
- Screen reader support info

**Notifications:**
- Email notifications
- Browser notifications
- Security alerts
- Feature updates

**Data Preferences:**
- Marketing emails (optional)
- Anonymous analytics
- Improvement program

**Next Steps:** Review and click "Next"

---

### Step 4: Security Setup

**Duration:** 2-3 minutes

**What You'll Verify:**
- Email verification status
- Password strength check

- Optional 2FA setup

**Email Verification:**
```
✓ Email verified: your@email.com
  (Verified on Nov 11, 2024)
```

**Password Check:**
- Current password strength displayed
- Recommendation if weak
- Option to change password
- Password rules explained

**Security Tips:**
- ✓ Use unique password
- ✓ Save in password manager
- ✓ Don't share credentials
- ✓ Enable 2FA (when available)

**What's Next:**
- Review security checklist
- Click "Next" to continue

## Tips for Best Results

1. **Use Real Information**
   - Your actual timezone
   - Preferred language
   - Accurate profile data

2. **Enable Security Features**
   - Keep 2FA in mind
   - Use strong password
   - Verify email

3. **Customize Settings**
   - Choose theme you prefer
   - Enable accessibility needs
   - Set notification preferences

4. **Don't Skip**
   - Each step has important info
   - Can complete later if needed
   - Available anytime in Settings

5. **Ask for Help**
   - Documentation links provided
   - FAQ available
   - Support contact info

## Skipping the Wizard

You can skip steps or the entire wizard:

**Skip Single Step:**
- Click "Skip" button
- Move to next step
- Can revisit later

**Skip Entire Wizard:**
- Click "Skip" on any screen
- Go directly to dashboard
- Restart from Settings anytime

**Restart Wizard:**
1. Go to Settings
2. Click "Help & Support"
3. Select "Restart Onboarding"
4. Wizard starts over

## What If I Make Mistakes?

### Changing Information

Most settings can be changed anytime in Settings:
- Profile information
- Theme preference
- Accessibility options
- Notification preferences

### Resetting Password

From Settings → Security:
1. Click "Change Password"
2. Enter current and new password
3. Changes apply immediately

### Recovering from Mistakes

- Email notifications turned on? Turn off in Settings
- Wrong timezone? Update in Profile
- Don't like theme? Switch in Settings
- Wrong language? Change in Preferences

## Common Questions

**Q: Can I restart the wizard?**
A: Yes! Go to Settings → Help → Restart Onboarding

**Q: What if I skip important steps?**
A: No problem! All settings can be configured later in Settings

**Q: Does wizard data get lost if I leave?**
A: No, your progress is saved. You can continue where you left off

**Q: Can I change settings after the wizard?**
A: Yes! All settings are fully configurable in Settings menu

**Q: Is there a time limit to complete the wizard?**
A: No, take your time! Completion saves automatically
