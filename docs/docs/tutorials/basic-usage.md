# Basic Usage Tutorial

Learn the fundamentals of using Workplace Tools effectively.

## Before You Start

Ensure you have:
- ✓ Completed account setup
- ✓ Passed onboarding wizard
- ✓ Verified email address
- ✓ Set up security preferences

**Time Required:** 15-20 minutes

## Common Tasks

### Task 1: Logging In

**Scenario:** Starting your day, need to access your account

**Steps:**
1. Navigate to application URL
2. Click "Sign In"
3. Enter email address
4. Enter password
5. Click "Sign In" button
6. Dashboard loads

**What You See:**
- Welcome message with your name
- Available features
- Quick action buttons
- Recent activity (if applicable)

**Helpful Tips:**
- Save password in browser
- Use password manager
- Check "Remember this device" (trusted devices only)
- Use "Forgot Password?" if needed

---

### Task 2: Changing Your Theme

**Scenario:** Eyes tired from bright screen, want to switch to dark mode

**Steps:**
1. Look top-right corner
2. Find theme toggle (sun/moon icon)
3. Click to switch
4. Dark theme applies immediately
5. Setting saves automatically

**Theme Options:**
- Light: Bright background, dark text
- Dark: Dark background, light text
- Auto: Follows system setting

**Keyboard Shortcut:**
- Most browsers: Use theme toggle button

---

### Task 3: Updating Your Profile

**Scenario:** Recently changed name, need to update account

**Steps:**
1. Click menu (top-right)
2. Select "Settings"
3. Click "Profile" tab
4. Click "Edit" button
5. Modify information:
   - Display Name
   - Timezone
   - Bio (optional)
6. Click "Save Changes"
7. Confirmation appears

**Profile Fields:**
- Display Name: How others see you
- Email: Cannot change (for security)
- Timezone: Important for timestamps
- Avatar: Profile picture (optional)

**Validation:**
- Name: 2-50 characters
- Email: Valid email format (read-only)
- Timezone: Standard timezone format

---

### Task 4: Managing Your Password

**Scenario:** Want to change password for security

**Steps:**
1. Go to Settings
2. Click "Security" tab
3. Click "Change Password"
4. Enter current password
5. Enter new password
6. Confirm new password
7. Click "Update Password"

**Password Requirements:**
- Minimum 12 characters
- Include uppercase and lowercase
- Include numbers
- Include special characters
- Not previously used
- Not username or email

**Best Practices:**
- Use unique password
- Save in password manager
- Change every 90 days
- Different from other accounts

---

### Task 5: Setting Notification Preferences

**Scenario:** Getting too many emails, want to customize

**Steps:**
1. Navigate to Settings
2. Click "Notifications"
3. Toggle options on/off:
   - ☑ Email digest
   - ☐ Alert notifications
   - ☑ Security alerts
   - ☐ Feature updates
4. Set frequency (if applicable):
   - Daily / Weekly / Monthly
5. Click "Save Preferences"
6. Changes apply immediately

**Notification Types:**
- Email: Sent to email address
- Browser: Popup notifications
- In-app: Notifications in dashboard
- SMS: Text messages (if available)

---

### Task 6: Viewing Your Account Activity

**Scenario:** Want to review what happened on your account

**Steps:**
1. Go to Settings
2. Click "Security" or "Activity"
3. View active sessions with:
   - Device type
   - Browser/OS
   - Location (if available)
   - Last activity time
4. Sign out unused sessions:
   - Click "Sign Out" next to device
   - Confirm action
5. Verify all recognized devices

---

### Task 7: Exporting Your Data

**Scenario:** Want backup of all your data

**Steps:**
1. Navigate to Settings
2. Click "Data & Privacy"
3. Click "Export My Data"
4. Choose format:
   - JSON (structured, recommended)
   - CSV (spreadsheet compatible)
   - PDF (document format)
5. Click "Export"
6. File downloads
7. Save to safe location

**What Gets Exported:**
- Profile information
- Account settings
- Activity history
- All personal data

**Not Exported:**
- Session tokens
- Authentication data
- System logs

---

### Task 8: Logging Out

**Scenario:** Finished work, need to secure account

**Steps:**
1. Click menu (top-right)
2. Click "Logout"
3. Confirmation dialog appears
4. Click "Yes, logout" to confirm
5. Redirect to login page
6. Session ends

**Security Notes:**
- Always logout on shared devices
- Logout when stepping away
- Can end sessions from Settings
- Revoke device access anytime

## Keyboard Shortcuts

**Navigation:**
- `Home` - Go to dashboard
- `?` - Show help (if available)

**Form Actions:**
- `Tab` - Move to next field
- `Shift+Tab` - Move to previous field
- `Enter` - Submit form/Click button
- `Esc` - Cancel/Close dialog

**Common Actions:**
- `Ctrl+S` / `Cmd+S` - Save (if available)
- `Ctrl+Z` / `Cmd+Z` - Undo (if available)
- `Ctrl+C` / `Cmd+C` - Copy
- `Ctrl+V` / `Cmd+V` - Paste

## Tips & Best Practices

1. **Keyboard Over Mouse**
   - Faster to navigate
   - Better accessibility
   - More efficient

2. **Use Your Browser Tools**
   - Password manager: Auto-fill credentials
   - Bookmarks: Quick access to app
   - Extensions: Additional functionality

3. **Organize Your Workspace**
   - Bookmark important pages
   - Note favorite features
   - Create quick reference

4. **Security First**
   - Logout on shared devices
   - Use strong passwords
   - Enable 2FA when available

5. **Keep Updated**
   - Install security patches
   - Update browser regularly
   - Clear cache periodically

## Common Issues

### Can't Click Buttons?
- Ensure JavaScript enabled
- Try different browser
- Clear cache
- Check internet connection

### Forms Won't Submit?
- Verify all required fields filled
- Check field validation (color changes)
- Look for error messages
- Try again or refresh page

### Text Not Visible?
- Adjust browser zoom (Ctrl++)
- Change theme
- Check accessibility settings
- Increase font size in Settings

### Slow Performance?
- Close unused tabs
- Clear browser cache
- Restart browser
- Check internet connection
