# Frequently Asked Questions

Answers to commonly asked questions about Workplace Tools.

## Getting Started

### Q: How do I create an account?

**A:** Sign up is easy:
1. Visit the application homepage
2. Click "Sign Up"
3. Enter your email address
4. Create a strong password
5. Verify your email address
6. Start using Workplace Tools!

The process takes about 2 minutes.

---

### Q: Do I need to install anything?

**A:** No installation required! Workplace Tools is:
- Web-based (works in any browser)
- Cloud-hosted (nothing to install locally)
- Progressive Web App (can install as app)

You can optionally install it on your device for a native-like experience.

---

### Q: What are the system requirements?

**A:** Minimum requirements:
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection (or offline mode for PWA)
- JavaScript enabled
- Cookies enabled

Recommended:
- High-speed internet
- 2GB+ RAM
- SSD storage
- Latest browser version

---

### Q: Is Workplace Tools free?

**A:** Yes! Workplace Tools is free to use with full features. Premium tiers may be available for advanced features.

---

### Q: How long does setup take?

**A:** Setup takes about 10-15 minutes:
- Account creation: 2 minutes
- Email verification: 5 minutes
- Onboarding wizard: 5 minutes
- Optional configuration: Variable

---

## Account & Security

### Q: How secure is my data?

**A:** Very secure! We use:
- Supabase for authentication
- HTTPS encryption
- Row-level security (RLS)
- Regular security audits
- SSL certificates
- Secure password hashing

See [Privacy Policy](./privacy-policy) for details.

---

### Q: Can I change my email address?

**A:** Yes! You can change your email in:
1. Settings → Profile
2. Enter new email
3. Verify new email address
4. Confirm change

Your old email becomes inactive once verified.

---

### Q: What happens if I forget my password?

**A:** No problem!
1. Click "Forgot Password?" on login
2. Enter your email
3. Check email for reset link
4. Follow link to set new password
5. Log in with new password

Reset links work for 24 hours.

---

### Q: Is two-factor authentication (2FA) available?

**A:** 2FA is planned for future releases. Currently only passwords are used.

For now, ensure your password is:
- At least 12 characters
- Unique (not used elsewhere)
- Complex (mix of character types)
- Secure (saved in password manager)

---

### Q: How often should I change my password?

**A:** Best practices:
- Change every 90 days for standard accounts
- Change immediately if suspicious activity
- Change after security breach
- Change before long absence
- Keep password unique per service

---

### Q: What if my account gets hacked?

**A:** Immediately:
1. Change your password
2. Review Settings → Security
3. Sign out all sessions
4. Check active devices
5. Report incident to support@workplace-tools.example.com

We'll investigate and help secure your account.

---

## Features & Functionality

### Q: Can I use Workplace Tools offline?

**A:** Yes! Install the PWA (Progressive Web App):
- Desktop: Click install icon
- Mobile: Use "Add to Home Screen"

Offline capabilities:
- ✅ View cached pages
- ✅ Navigate app
- ✅ Fill out forms
- ❌ Real-time data updates
- ❌ API access

Changes sync when you go back online.

---

### Q: Does Workplace Tools work on mobile?

**A:** Absolutely! The app works on:
- iOS Safari
- Android Chrome
- Any modern mobile browser

Responsive design adapts to screen size. Install PWA for better experience.

---

### Q: Can I access Workplace Tools from multiple devices?

**A:** Yes! Log in on multiple devices:
- Same account on all devices
- Data syncs automatically
- Settings available everywhere
- Manage sessions in Settings

Each device gets its own session for security.

---

### Q: How do I export my data?

**A:** Export anytime:
1. Settings → Data & Privacy
2. Click "Export My Data"
3. Choose format:
   - JSON (complete, machine-readable)
   - CSV (spreadsheet format)
   - PDF (document format)
4. Download file
5. Store safely

---

### Q: Can I delete my account?

**A:** Yes, you can delete your account:
1. Settings → Account → Delete Account
2. Confirm action
3. 30-day recovery period
4. Permanently deleted after 30 days

Note: Deletion is permanent after 30 days. Export data first!

---

### Q: How long until my data is deleted after I delete my account?

**A:** Timeline:
- Day 1-30: Recoverable (contact support)
- Day 30+: Permanently deleted
- No recovery possible after 30 days

We keep backups for compliance, not recovery.

---

## Performance & Technical

### Q: Why is the app loading slowly?

**A:** Check these first:
1. Internet speed (test at speedtest.net)
2. Browser cache (clear it)
3. Browser updates (install latest)
4. Device performance (close unused apps)
5. Network congestion (try off-peak times)

See [Troubleshooting](./troubleshooting#performance-issues) for more.

---

### Q: Which browsers are supported?

**A:** Supported browsers:
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+
- Mobile browsers (iOS Safari, Chrome Mobile)

Older browsers may have issues. Update to latest version.

## Privacy & Policies

### Q: What data do you collect?

**A:** We collect:
- Account information (name, email)
- Usage analytics (non-identifying)
- Device information
- IP address
- Login history

We don't sell data. See [Privacy Policy](./privacy-policy).

---

### Q: How is my data encrypted?

**A:** Encryption methods:
- In transit: HTTPS/TLS
- At rest: AES-256 (industry standard)
- Authentication: Supabase hashing
- PII: Encrypted when stored

Your data is encrypted by default.

---

### Q: Can I opt-out of analytics?

**A:** Yes! Control analytics:
1. Settings → Privacy
2. Toggle "Analytics" off
3. Uncheck "Improvement Program"
4. Save preferences

We respect your privacy choices.

---

### Q: What's your data retention policy?

**A:** We retain:
- Active data: Indefinitely (until deletion)
- Deleted accounts: 30 days
- Backups: 6 months
- Logs: 90 days
- Activity: 1 year

See [Privacy Policy](./privacy-policy) for complete retention schedule.

  - Access your data
  - Export data
