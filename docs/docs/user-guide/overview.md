## Authentication

### Creating an Account

1. Visit the application homepage
2. Click "Sign Up"
3. Enter your email address
4. Choose a secure password
5. Verify your email address
6. You're ready to go!

### Logging In

1. Click "Sign In" on the homepage
2. Enter your email and password
3. Click "Sign In"
4. You'll be redirected to your dashboard

### Password Recovery

1. Click "Forgot Password" on login page
2. Enter your email address
3. Check your email for recovery link
4. Follow the link to reset your password
5. Create a new password
6. Log in with your new password

## Theme Preferences

### Switching Themes

1. Look for the theme toggle in the top-right corner
2. Click to switch between:
   - **Light Theme** - Bright, easy on eyes in daylight
   - **Dark Theme** - Reduced eye strain in low light

Your preference is automatically saved and will be restored on your next visit.

## Offline Support

Workplace Tools works offline thanks to Progressive Web App (PWA) technology!

### What Works Offline

- Viewing previously loaded pages
- Basic navigation
- Reading cached content
- Filling out forms (synced when online)

### What Requires Internet

- Authentication/login
- Syncing data
- Real-time updates
- External API calls

### Going Offline

1. The app automatically detects internet loss
2. You'll see an offline indicator
3. Cached content remains available
4. Actions queue for sync when online

## Accessibility

We're committed to accessibility for all users.

### Keyboard Navigation

- `Tab` - Move between elements
- `Enter` - Activate buttons/links
- `Esc` - Close dialogs
- `Arrow Keys` - Navigate menus

### Screen Reader Support

- Full ARIA labels
- Semantic HTML structure
- Alternative text for images
- Form field associations

### Text Size

- Use browser zoom (Ctrl/Cmd + Plus)
- Some features support font size preferences
- Check Settings for typography options

## Privacy & Security

### Your Data

- All authentication is handled by Supabase
- Data is encrypted in transit (HTTPS)
- Your data is yours - we don't sell it
- See [Privacy Policy](../support/privacy-policy) for details

### Security Best Practices

1. Use a strong, unique password
2. Enable two-factor authentication (if available)
3. Don't share your login credentials
4. Use secure WiFi networks
5. Log out on shared devices
