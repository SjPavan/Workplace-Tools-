# Features Guide

Explore all the features available in Workplace Tools.

## Core Features

### Authentication & Security

**Secure Login System**
- Email and password authentication
- Supabase-powered backend
- Session management
- Automatic logout for security

**Account Management**
- Update profile information
- Change password
- Manage login sessions
- Delete account (if needed)

### Dashboard

**Personal Dashboard**
- Overview of all available tools
- Quick access shortcuts
- Status indicators
- Personalized greeting

**Tool Discovery**
- Browse available tools
- View tool descriptions
- See recent activity
- Access favorites

### User Preferences

**Theme Settings**
- Light and dark modes
- Automatic switching based on system preference
- Persistent storage of preference

**Language & Localization**
- English language support
- Extensible for additional languages
- Locale-aware date/time formatting

**Accessibility Options**
- Keyboard navigation
- Screen reader support
- High contrast mode (if available)
- Font size adjustments

### Data Management

**Your Information**
- View your profile data
- Update account details
- Manage connected services
- View activity logs

**Data Export**
- Export personal data
- Multiple format support
- Secure download
- GDPR compliant

### Offline Support

**Progressive Web App (PWA)**
- Install as standalone app
- Works without internet
- Offline page caching
- Automatic sync when online

**Installing PWA**

On Desktop (Chrome):
1. Open the app URL
2. Click the "Install" icon (top-right)
3. Follow prompts
4. Launch from applications menu

On Mobile (iOS):
1. Open in Safari
2. Tap "Share" button
3. Tap "Add to Home Screen"
4. Confirm to add

On Mobile (Android):
1. Open in Chrome
2. Tap menu (three dots)
3. Tap "Install app"
4. Confirm installation
