# Workplace Tools

A collection of standalone HTML utilities built with vanilla HTML, CSS, and JavaScript. These tools are designed for everyday workplace productivity and can be used directly in your browser without any installation.

## Available Tools

### Text Processing Tools

- **[Sentence Case Converter](sentence_case_converter.html)** - Convert any text to proper sentence case with automatic capitalization of the first letter of each sentence.
- **[Title Case Converter](title_case_converter.html)** - Convert text to title case, perfect for headlines, titles, and headings.
- **[Text Cleaner](text_cleaner.html)** - Remove extra spaces, line breaks, and normalize text formatting with customizable cleaning options.
- **[Text Analyzer](text_analyzer.html)** - Get detailed statistics about your text including character count, word count, reading time, and more.

## Features

- **Single-file utilities** - Each tool is contained in a single HTML file
- **No dependencies** - Built with vanilla HTML, CSS, and JavaScript
- **Clipboard integration** - Easy copy/paste functionality
- **Responsive design** - Works on desktop and mobile devices
- **Dark theme** - Easy on the eyes for extended use
- **Auto-conversion** - Real-time conversion as you type

## Usage

Simply open any HTML file in your web browser to use the tool. No installation or setup required.
